
## Урок 10 (ночь 21-22.11). Entware-деплой и Reality-туннель — полный разбор
1. **Загрузка файлов в том (том Netcraze)**: RCI put (анонс) + POST **/fui** (БЕЗ слэша!).
   Слэш = 405. Перед POST создать каталог: `mkdir uuid:/path` (иначе 500).
   Большие файлы (>5МБ): нужен keepalive-поток put каждые ~2с, иначе 502.
   30МБ одним куском = смерть медленной флешки: качать ВНУТРЬ роутера через
   Entware curl --socks5-hostname (рабочий прокси) — 2МБ/с стабильно.
2. **NDMS CLI**: `ls` = максимум ~10 записей; `more` = файлы до ~几百KB,
   бинарники отказом; корневые файлы `more uuid:/файл` = parse error
   (копировать в подкаталог). `copy` = только между локальными томами.
3. **Синтаксис drift**: KeeneticOS 5.1.8 (`wireguard private-key`) vs
   Netcraze 5.1.9 (`wireguard peer` = 44-симв. ключ С "="; private-key
   внутри `wireguard` контекста). Всегда запрашивать `?` в контексте!
4. **confdir xray = все *.json сливаются!** Тест-конфиги удалять сразу,
   иначе мердж-каша = мистические сбои роутинга.
5. **Reality "received real certificate"** = сервер отверг аутентификацию.
   Проверять: часы (±90с!), ключи (pbk/sid!), версию клиента vs сервера
   (26.10+ vs старый сервер несовместимы: у нас рабочий = yichya 26.9.9).
   Балансер leastPing выбирает "живой" канал с рабочей маскировкой —
   мёртвый upstream с сайт-прикрытием выглядит живым! Прямой outboundTag
   надёжнее балансера.
6. **Переадресация портов vs интерфейсные ACL**: ACL на WAN не открывает
   INPUT-порты Entware (только FORWARD). Доступ к socks/ssh Entware с WAN
   невозможен без REDIRECT на его стороне — используй туннель или LAN.
7. **Entware dropbear**: XKeen ставит на 222 (или переопределяй
   /opt/etc/config/dropbear.conf). Root-пароль = пароль роутера (XKeen)
   или keenetic (официальный установщик Entware).
8. **Doctor v2** (doctor2.py): проверяет WG-туннель, dropbear, xray,
   exit-IP через оба socks, MTU. Запускать после ЛЮБОГО изменения.
9. **Тест-инструменты**: все bash = с timeout; python -I; ugrep-алиас
   ломает сложные grep-пайпы — использовать python для обработки вывода.
